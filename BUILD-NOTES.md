NusaStat build notes, in plain words.

What this entry is: NusaStat, an original national statistics portal for Indonesia, built as static files with no build step and no network requests. Every figure comes from published Badan Pusat Statistik (BPS) statistics for 2019 to 2024, and every figure on the site names its source and year.

Pages: a dashboard with six headline indicators and a switchable main chart; Penduduk (population trend and the eight most populous provinces); Ekonomi (growth, GDP per capita, exports versus imports, and the 2024 structure of GDP, with a period switch between 2019–2024 and 2021–2024); Ketenagakerjaan (open unemployment with a sortable, searchable, downloadable table); Harga (annual inflation with a line-or-bar switch); Kesejahteraan (poverty, human development index, and Gini ratio); Wilayah (provinces by population from the 2020 census, with a searchable and sortable table and CSV download); and Tentang (sources and methodology).

How it is built: vanilla JavaScript only, no framework and no vendored library, so the first load is ten files and under nineteen kilobytes gzipped. Charts are hand-drawn SVG line, bar, grouped-bar, donut, and horizontal-bar charts. Source is split by job: data holds the figures, charts draws them, components builds shared tables and cards, pages renders each route, router handles hash navigation, and the app file boots the site.

Verification done by the builder: all eight routes render in headless Chromium at desktop and phone sizes with zero console errors; the dashboard indicator switch, the economy period switch, the inflation chart-type switch, the province table search (Jawa narrows nineteen rows to three), and the province table sort all work; screenshots are real renders of the site. The hand-in program was run twice to two separate output folders and the outputs were byte-identical. The kit check passes competition open, snapshot, license, and entrypoint; the only failure is the expected transcripts check, because the parent bundles the transcripts at submit time. The GitHub repository, push, bundle, and submit are the parent's steps, not done here.

Known gaps: every route and every control was exercised in the browser, but the CSV download button was wired and code-checked rather than clicked through in the browser run, so it is the least-tested control on the site. The figures use the latest BPS published values the builder could state confidently; two derived statements (the Java share of population and the 2024 trade surplus) are arithmetic from those published values and are labelled as such on the pages.
